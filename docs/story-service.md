# 서비스 스토리 — 허들링 앱 (MVP 1차)

출처: docs/prd.md

## 유저스토리

- US-1 무료 학습자(비회원·무료 회원)가 카테고리별 공개 학습자료와 유료 콘텐츠 미리보기를 둘러본다. (PRD 3-1, 6-1)
- US-2 유료 회원이 강의자료·다시보기·템플릿·스킬/프롬프트 카드를 한곳에서 찾아 열람·복사·다운로드한다. (3-2, 6-2, 6-3)
- US-3 유료 회원이 매달 미션 산출물을 제출하고, 제출 완료된 제출물을 내 자산으로 전환한다. (3-3, 6-4)
- US-4 판매 승인 회원이 내 자산 중 일부를 판매 신청하고 검수 상태를 확인한다. (3-4, 6-5, 7-4)
- US-5 운영자가 판매 기준 체크리스트로 판매 신청을 승인/수정 요청/반려하고, 유료 회원을 판매 승인 회원으로 수동 전환한다. (3-6, 6-7)

## ★ 어기면 안 되는 것 (판정 기준 · PRD 14장)

- ★1 멤버 자료는 기본 비공개. 본인이 선택할 때만 멤버 공개·판매 신청.
  - 판정: 공개 범위 필드마다 "기본값: 비공개" 표기 / '판매 신청' 옵션은 seller 역할에만 노출
- ★2 판매 자산은 운영자 검수를 통과해야 한다.
  - 판정: 판매 신청 상태 흐름에 "검수 대기" 존재 / "임시저장 → 승인됨" 직행 경로 0개

## 범위 밖 (설계 문서에 나오면 게이트가 차단)

- Phase 2: 허들링 픽, 구매자 흐름, 판매 중, 판매 중지
- Phase 3: 결제, 정산, 판매 수익
- MVP 제외: 미션 피드백, AI 1차 검수, 실시간 채팅, 커뮤니티 피드, 리뷰/평점, 자동 추천, 오픈마켓
- 키워드 검사는 정확한 문구로만 한다. ("피드백" 단독은 판매 검수 코멘트와 겹치므로 "미션 피드백"으로만 차단)
