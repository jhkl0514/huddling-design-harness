# 분석과 반영 포인트 — 내 자산

| 번호 | 반영 포인트 | 출처 번호 |
|---|---|---|
| 1 | 내 자산 목록 상단에 판매 신청 상태 칩 필터(전체 / 임시저장 / 검수 대기 / 수정 요청 / 승인됨 / 반려)를 두어 상태별로 바로 좁혀 본다 | 2, 8 |
| 2 | 자산 카드 좌상단에 상태 배지(공개 범위 + 판매 신청 상태)를 붙여 목록에서 카드를 열지 않고도 현재 상태를 알 수 있게 한다 | 1, 2, 3 |
| 3 | 목록 상단에 "내 자산 총 N건" 형태의 건수 요약을 두어 자산화 진행 정도를 한눈에 보여준다 | 3 |
| 4 | 새 자산 등록 폼 최상단에 공개 범위 라디오(비공개 / 멤버 공개 / 판매 신청)를 두고 기본값은 비공개로 선택해 둔다. 선택한 범위의 의미는 상단 안내 배너로 풀어 쓴다. 판매 신청 옵션은 seller 역할에만 노출한다 | 5 |
| 5 | 자산 상세에 판매 신청 흐름을 세로 단계 타임라인(임시저장 → 검수 대기 → 승인됨 / 수정 요청 / 반려)으로 보여주어, 운영자 검수를 반드시 거친다는 점을 드러낸다 | 4 |
| 6 | 등록 폼은 제목·설명·파일 첨부·공개 범위를 섹션으로 나누고, 필수 항목이 채워지기 전까지 등록 CTA를 비활성으로 둔다 | 6 |
| 7 | 자산이 없을 때 빈 화면에 안내 문구와 "새 자산 등록" CTA를 두고, 제출 완료된 미션 제출물을 자산으로 전환하는 경로도 함께 안내한다 | 7 |
| 8 | 카드 하단에 상태별 액션 버튼을 둔다(임시저장: 이어서 작성 / 수정 요청: 운영자 코멘트 보기·수정하기 / 반려: 사유 보기) | 1, 2 |
